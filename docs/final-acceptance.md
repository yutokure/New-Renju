# 最終受入れ判定（検証中・暫定）

## 判定の意味

- PASS: その限定範囲の実装・試験・レビューの証拠が揃った。
- CHANGES REQUESTED: 残る制限・証拠不足があり、全体完了PASSとしない。
- REJECTED: 設計要件と両立しない等で採用しない。未試験というだけでREJECTEDにはしない。

## 最終ローカル証拠の要約

467テスト合格。Very Hardは同一1.5秒で改善Hard20勝4敗/旧Hard22勝2敗、通常設定16勝0敗。ただし8開局群の有限比較。Hard対旧Hardは5勝6敗5打切りで非退行未確定。実Windows Python GUIとメモリ上限/親終了検証は成功、配布exeの一時フォルダワーカーは未合格。詳細は[検証報告](validation-results.md)。

## 既知の残る制限

1. 12ms内に再判定できない極端な合法黒着手は未判定として不適用。バックグラウンドでその一点の判定を自動継続する機構は未実装。
2. 深いVCT/実戦到達履歴付きの独立正解コーパスは小さい。多くはRIF定義に基づく合成局面と手証明。
3. 一般探索は候補幅制限と強制応手の延長上限を持つ推定値で、必勝証明とはしない。
4. 非WindowsではOSメモリ上限非対応を明示。構造的キャッシュ上限と壁時計停止のみ。
5. 大会開局・時計・申し立て・見逃し禁手・正式パス手順は対象外。
6. 開局8群の有限実験。狙った条件下でHardに優位でも、普遍的棋力/Elo/人間上級者を上回るとは主張しない。
