# Hard非退行・事前固定追加試験

## なぜ別の標本か

初期8開局16局はHard5勝6敗5打切りで、棋力非退行を確定できない。浅い探索の単発敗局だけを最適化せず、評価器/探索深度/時間は変更しないまま、より多様な初期状態で比較する。

## 測定前に固定した条件

- サンプル生成: `random.Random(202611081245)`。AI出力/勝敗を一切参照しない。
- 15×15/5目/同じ正式審判。簡易序盤を含む5/7/9手の合法履歴16種類。
- 追加手は盤中央7×7・既存石からChebyshev距離2以内の合法点を一様選択し、完成済み終局配置は採用しない。
- この選択も無作為全局面標本ではなく、人為的な局所開局分布である。重複幾何や似た戦略は独立とは限らない。
- 事前履歴JSONと生成コードを測定前のcommit `1fb4cf2` へ保存。結果を見て開局を入替えたり不利な試合を捨てない。
- 32局・各開局で先後交替、双方1.5秒、Hard深さ2のまま、160手上限。全探索は直列、他の重いビルド/性能試験と同時実行しない。
- 旧AIはGit`d4b2edd`のAIソース、現在のBoard/正式ルールを共通審判に使用する。旧配布版の誤審判まで再現しない。
- 新ランナーは各ゲーム開始時のコアソースSHA256、全棋譜、所要時間、勝敗、例外/非法手/打切りを記録。

## 統計と判定の境界

初期8開局の結果とは別の表で報告する。単純に全てを独立局として混ぜない。生のW/L/打切り、決着率のWilson参考区間、開局群の符号集計を併記する。打切りを引分扱いせず、不具合を都合よく除外しない。

この追加試験を始める時点で非劣性マージンや十分な検出力を設計していないため、わずかに得点が上がっただけで統計的非退行PASSとはしない。対戦結果と、別の独立3×3/4×4浅い全幅オラクルによる探索機械的正確性は別の受入れ項目である。

## 完了結果

**32局: Hard18勝9敗5打切り、エラー0、引分0。** 決着27局の勝率66.67%、独立試行と仮定した参考Wilson95%区間 **47.82〜81.36%**。初期8開局5勝6敗5打切りも保持し、追加結果で置き換えない。

16開局群のうち、既知の決着だけによる得点が>0.5は7群、<0.5は2群、同点6群、両方打切りで得点未定1群。非同点9群の正符号の参考Wilson区間45.26〜93.68%。打切りを除いた群得点にも選択性があるため、全開局の非劣性確率とは呼ばない。

全2510着手を共有正式審判で再生合法、独立実装の終局幾何一致、終局後の着手なし。全32ゲーム開始時の5コアソースSHA256は同一。1.5秒+100ms超過の記録なし。生記録/群集計/再生監査は `matches-hard-diverse-predeclared.json` / `strength-hard-diverse-summary.json` / `replay-hard-diverse.json`。
