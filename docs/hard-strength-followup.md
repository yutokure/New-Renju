# Hard棋力非退行の追跡

## 判定: CHANGES REQUESTED

現行Hard対旧Hard（同じ正式ルール審判、各1.5秒、先後交替、8開局、16局、100手打切り）は **5勝6敗5打切り、エラー0**。決着11局の勝率45.45%、Wilson95%区間 **21.27%〜71.99%**。先後・開局相関と打切りがあり、棋力低下も非低下もこの少数例では確定しない。要求された「意図しない棋力低下なし」をPASSにはしない。

## 負けの調査

本体修正担当とは別の親と担当エージェントが記録を再生し、以下を確認した。

- 5件の調査済み敗局は、最後のHard番ですでに相手の合法な五連完成点が2箇所あった。唯一の即勝利防御を見落としたタイムアウト事故ではない。
- 各敗局の最大思考は約0.25〜0.71秒で、1.5秒上限に到達していない。完成深さ2での浅い戦術/静的評価の限界を示す。
- 例: game4の35手目付近、Hard(8,10)に対して白(7,10)が両空き四を作った。直接(7,10)に守っても白(5,10)が別の四を作り、深さ2評価は-18,004,000対-18,004,500。根ですでに別の攻めを許しており、単純な1点防御の追加では解決しない。
- 例: game12の45手目付近、Hard(2,13)と直接防御(5,12)もそれぞれ別の棒四を許し、-17,999,000対-17,999,500だった。
- 旧評価器との比較で、5目の長さ優先greedyパターン順・端パターン挿入順・重み・絶対値同点処理は維持されている。意図的な差は黒長連の誤勝利除去と終局点の階層修正。
- 着手の変化は、旧set列挙から座標同点順への決定化、last_move修正により実際に有効になった既存の強制応手絞り込み、正式禁手の共有、完成探索/期限管理などからも生じ得る。αβ根の境界渡しには確認された符号/切断バグはなかった。

## 方針

16局を見て評価重みを都合よく変更したり、正確性修正を戻したり、HardへVCF/VCTを入れて勝率だけ上げることはしない。既存軽量設計を守る。より多様な独立開局と長い打切り、旧審判と現審判の要因分離、同点方針による棋風変化の比較が必要。

独立の小盤depth2全幅オラクル追加調査では、20固定局面中1局面で既存の強制応手絞込みによる地平差を確認した。相手に防御を強制する単一脅威の静的スコアを、2完成点を持つ実際のforkより高くする場合がある。これはαβ/TTの符号バグではなく、温存した浅い戦術選択の制限である。全幅2plyと同値だとは呼ばず、この局面も独立した特徴づけテスト/文書へ残す。Hardへ新しいVCFや深い探索を追加してこの標本だけ直すことはしない。

これはVery Hardの優位性とは別の受入れ項目で、Hard非退行が未確定のまま全体をPASSとしない。原記録: `benchmarks/results/matches-hard-vs-old-1_5.json`、再生監査は全1046着手合法・終局幾何一致。
