## 根本原因
画面の状態・操作・ルール情報が分散し、ゲーム中はモード／難易度／目数／簡易開局を確認しにくい。無効な着手の通知が位置マーカーだけで占有／開局／黒禁手を区別できず、英語のメニューと日本語の状態・Popupが混在する。白文字と明灰色Buttonの低コントラスト、設定値の横幅不足も読みやすさを損ねる。

## 再現条件・期待と実際
通常起動→設定→開始で、5目とカスタム目数の差、公式大会開局との差、最初の合法点、履歴閲覧／思考／判定未完了の操作を画面から知る。期待: 実装どおりの説明と状態・確定できる範囲の無効理由が一貫表示。実際: 一部はREADMEだけにあり、無効理由や現在設定が画面に出ない。画面上の英日混在とコントラストが理解を妨げる。

## 根拠・影響
main 28cec77 の main.py設定UI、game.py:_draw_status_and_turn/_apply_move、constants.py:BUTTON_TEXT_COLOR=WHITE/BUTTON_COLOR=(200,200,200)。G04発見。全利用者、特に初回対局。

## 推奨対応・受入条件
重要UIを一貫した英語へ統一（日本語定石名は固有名として保持）、画面内Rules説明、状態・モード・目数・確定できる理由の表示。UNKNOWNを禁手扱いせず、補助表示の意味を説明。文字色・配置・設定値領域を修正。既存対局機能と4難易度を回帰確認。大規模多言語化／リサイズ／大会開局実装はしない。
