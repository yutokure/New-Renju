## Fonts

### UI font (DejaVu Sans Bold)

`fonts/UiSans.ttf` is an unmodified DejaVu Sans Bold 2.35 font from the official Matplotlib 3.10.1 distribution, renamed only at the filesystem level. Its exact bytes match the official versioned upstream font. Copyright (c) 2003 Bitstream, Inc.; Copyright (c) 2006 Tavmjong Bah; DejaVu changes are in the public domain. See DejaVu-LICENSE.txt for both original permission notices, trademark/naming conditions and disclaimers, and DejaVu-PROVENANCE.md for official URLs, version, byte counts and SHA-256. The original font permits distribution as part of a larger software package; it is not offered separately for sale here. Matplotlib code is not bundled by this asset copy.

`YasashisaGothicBold-V2.otf` is the repository's existing unmodified font. Embedded metadata identifies `Copyright(c)Fontna.com , Copyright(c) 2019 M+ FONTS PROJECT`, family `YasashisaGothicBoldV2 bold`, version `2.063;hotconv 1.0.109;makeotfexe 2.5.65596`.

Fontna's official family page expressly licenses use/embedding under M+ terms and credits Fontna (kana) and M+ FONTS PROJECT:
https://www.fontna.com/blog/yasashisagothic_b.html

The official legacy family distribution remains available at:

Its original LICENSE_E, LICENSE_J and Fontna readme are included here (Japanese EUC-JP converted to UTF-8 without changing the text). M+ grants unlimited use/copy/distribution with or without modification, commercial or noncommercial, without warranty. No new OFL terms are retroactively substituted for this legacy font.

### Historical Pygame default font (excluded from the corrected release)

The previous artifact included Pygame's 2002 Revision 0.4 `freesansbold.ttf`, carrying `Copyright 2002 Free Software Foundation.` and an unversioned GPL notice. The exact upstream TTF was matched, but its preferred editable SFD source/build correspondence was not established. FreeSans-PROVENANCE.md preserves the exact metadata, hashes, official historical-source findings and limits. GPL-2.0.txt and FreeFont-historical-README.txt preserve original license/historical text without pretending that this supplies the missing exact source. The corrected release uses UiSans instead and must omit every copy of `freesansbold.ttf`; do not infer approval to ship the old font from the inclusion of these research notices.
