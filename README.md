# Gomoku 2.0（五目並べ）

Windows 向けの、手軽に対局・振り返りができる五目並べゲームです。人間同士の対局、4段階の AI、連珠の勝敗・禁手コア、カスタム目数、棋譜保存、履歴閲覧、研究用の静的評価表示を備えています。

**表示バージョン:** 2.0 ／ **内部バージョン:** 2.0.0 ／ **リリースタグ:** `v2.0.0`

> **PORTABLE 仕様を正式採用・配布候補の受入検証済み:** Windows 11 x64（build 26300）の非管理者・引数なし起動と、日本語・空白を含む場所に展開した ZIP で、記録にある対局・保存・読み込み・終了を確認しました。これは全 Windows 環境の保証や公開完了の宣言ではありません。確認範囲は [G05 PORTABLE 受入記録](<docs/G05_PORTABLE_ACCEPTANCE.md>)、変更点は [2.0 リリースノート](<docs/RELEASE_NOTES_2.0.md>)、**公開状態・最終 SHA-256 は [公式 Release](https://github.com/yutokure/New-Renju/releases) を参照**してください。

## 主な機能

- **4つの対局モード:** Human vs Human / Human vs AI / AI vs Human / AI vs AI。
- **4段階の AI:** Easy / Normal / Hard / Very Hard。AI の思考は別プロセスで行い、Menu・履歴移動・終了などで取り消します。
- **設定可能な盤面:** 9・11・13・15・17・19 路、勝利条件は 3〜7 目。
- **5目の連珠コア:** 黒はちょうど5、白は5以上で勝利。黒の三三・四四・長連を確認します。大会の開局手順全体には対応しません。
- **対局の補助:** 5目専用の脅威パターン線、Attack / Defense / Pressure ポップアップ、定石名テロップ、着手アニメーション。
- **振り返り:** 現在の対局を変更しない履歴閲覧と、`Research: Hard static` による候補手の静的評価。
- **セーブ・ロード:** JSON 形式。一意名で安全に保存し、有効な旧 v1 / v2 棋譜を現行ルールで全手再検証して再開します。

UI は **英語**です。本書は日本語で操作を説明します。日本語の定石名は固有名として表示されます。

## 動作環境

### Windows 配布版

- **Windows 10 / 11、x64（64 bit）** が正式な配布対象です。G05 の実機受入環境は Windows 11 x64（build 26300）で、Windows 10 の実機検証済みを意味しません。
- ZIP を展開して使う **onedir 型のスタンドアロン版**です。Python や Pygame の別途インストールは不要です。
- 800×600 の固定サイズのウィンドウを表示できる画面と、マウス・キーボードを使用します。ウィンドウのリサイズには対応しません。
- AI の応答時間は PC の性能・負荷・局面で変わります。全局面での即時応答は保証しません。
- フォルダ一式を**書き込み可能な場所へ展開する PORTABLE 版**です。通常利用で管理者権限・ACL の変更・起動引数は必要ありません。読み取り専用のインストール先での保存・ワーカー作成はエラーになり、別の場所へ黙って切り替わりません。組織管理 PC の実行制限は管理者に相談してください。

### ソース版（開発者向け）

Python と [依存ライブラリ一覧](<requirements.txt>) の導入が必要です。従来のローカル検証環境は Python 3.12 系です。Windows 配布版と、他 OS でのソース実行の保証範囲は同じではありません。

```powershell
python -m pip install -r requirements.txt
python main.py
```

ソース実行の入口は [main.py](<main.py>) です。

## ダウンロードとインストール不要の起動

配布物の公開状態・最終 SHA-256 は [公式 Release](https://github.com/yutokure/New-Renju/releases) で確認してください。2.0 の公開単位はタグ `v2.0.0`、配布 ZIP 名は `Gomoku-2.0-Windows-x64.zip` です。この README 自体は公開完了を示すものではありません。

1. 公式リポジトリ、タグ、バージョン、ファイル名を確認して ZIP をダウンロードします。
2. 公開元が示す SHA-256 チェックサムがある場合は照合します。不一致や出所不明のファイルは実行しないでください。
3. ZIP を右クリックして「すべて展開」し、フォルダ一式を手元の書き込み可能な場所へ展開します。
4. 展開したフォルダ内の `Gomoku 2.0.exe` をダブルクリックします。**起動引数は不要**です。
5. exe だけを取り出さず、`_internal` などの同梱フォルダ・データ・ライセンス文書をそのまま保ってください。ZIP 内から直接起動しないでください。移動・バックアップはアプリを終了してから、exe と同じ場所の棋譜も含めてフォルダ一式で行います。

**Windows SmartScreen 等の警告について:** 警告は安全性を保証するものでも、無害だと判断してよいものでもありません。まず公式の入手元とチェックサムを確認してください。確認できなければ中止し、発行元に問い合わせてください。保護機能の一律無効化、無条件の警告回避、管理者実行、ACL 緩和は推奨しません。詳しくは [ユーザーマニュアル](<docs/USER_MANUAL.md#troubleshooting>) を参照してください。

## 最初の対局

1. `Settings` で `Board Size: 15x15`、`Win Length: 5`、`Game Mode: Human vs AI`、`AI Difficulty: Normal` を選び、`Back` で戻ります（これらが初期設定です）。
2. `Start New Game` をクリックします。黒が先手です。Human vs AI では人間が黒、AI が白です。
3. 盤の**交点**をクリックして着手します。簡易開局により、初手の黒は中央、2手目の白は中央の真上か右上、3手目の黒は中央5×5以内に限られます。これは全対応盤面・目数に適用します。
4. 5目では、黒はちょうど5個、白は5個以上を縦・横・斜めに並べると勝ちです。黒の確定した禁手には着手できません。カスタム3・4・6・7目は両色とも指定数以上で勝ち、黒専用の禁手はありません。
5. 保存は `Save Game` または `S`。履歴は `< Prev` / `Next >`。終了は `Menu` または `Esc` で戻って `Quit` です。**Menu や終了は自動保存ではありません。**

画面内の `Rules & controls` / `Rules` にもルールと操作を掲載しています。全15章の説明は [ユーザーマニュアル](<docs/USER_MANUAL.md>) を参照してください。

## AI と補助表示の読み方

| 表示 | 概要 | 注意点 |
|---|---|---|
| Easy | 合法手からランダムに選択 | 初心者向けの相手。最善手は保証しません |
| Normal | 即勝ち・即防御や局所形を優先 | 完全な先読みではありません |
| Hard | 反復深化 Minimax / αβ、局所評価、局面表 | 標準は深さ2・1.5秒。候補絞り込みがあり、必勝証明ではありません |
| Very Hard | 独立した VCF / VCT 戦術探索と反復深化 Negamax / αβ | 標準5秒。時間・深さ・候補幅に上限があり、完全解法ではありません |

従来の検証では特定の開局群・時間条件で Very Hard の優位が観測されていますが、全局面・全相手への普遍的な強さ、Elo、上級者以上の棋力は主張しません。Hard の棋力非退行にも証拠不足が残ります。数値や条件は [過去の検証報告](<docs/validation-results.md>) を参照してください。G01〜G05 では棋力・探索・評価関数の改修を対象としていません。

- 色付き線と Attack / Defense / Pressure は **5目専用の局所パターン補助**です。正式な禁手判定や必勝の証明ではありません。
- 研究値は **表示局面の手番側から見た Hard の静的推定**です。Very Hard の探索値でも勝率でもありません。
- 影の付いた点は確認済みの制限を表しますが、**無印の点が合法とは限りません**。`partial / unconfirmed` は全点確認済みという意味ではありません。
- `UNKNOWN / unplayed` は合法・禁手を確定できなかった状態です。石は置かれません。`R` で再判定するか、人間の手番なら別の交点を選ぶか、`Menu` に戻ってください。自動で無限に再試行はしません。
- 定石名データは名称表示専用で、AI の検証済み最善手帳ではありません。

## 保存先と互換性

G05 では **PORTABLE を既定仕様として正式採用**し、実 exe・展開 ZIP で配布候補の受入を確認しました（[検証範囲](<docs/G05_PORTABLE_ACCEPTANCE.md>)）。凍結配布版の基準は **`sys.executable` が指す exe の親フォルダ**です。起動時のカレントディレクトリやショートカットの作業フォルダではありません。

| 用途 | 場所 |
|---|---|
| Windows 凍結配布版の棋譜保存先 | exe と同じフォルダへ `gomoku_save_*.json` を直接保存（`Saves` サブフォルダではありません） |
| Windows 凍結配布版のワーカー一時通信領域 | exe の親フォルダ配下の `workers/renju-ai-<uuid>` |
| ソース版の棋譜保存先 | 実行時のカレントディレクトリ |
| Windows ソース版のワーカー一時通信領域 | ソースプロジェクトの `workers/renju-ai-<uuid>`（カレントディレクトリ基準ではありません） |

`<uuid>` はワーカーごとの一意な識別子です。LocalAppData や TEMP は既定の保存先・ワーカー領域として使いません。書き込み不能時に別フォルダへ黙って切り替えず、保存・ワーカー作成の失敗を通知します。読み取り専用のインストール先ではなく、ZIP 全体を書き込み可能な場所へ展開してください。

`Load Game` は凍結配布版の exe と同じフォルダに加え、**現在のカレントディレクトリにある旧 `gomoku_save_*.json` を読み込み用にだけ列挙**します。旧 cwd の探索は新規保存先を変えず、自動移動・自動移行・上書きもしません。別のフォルダにある旧棋譜はバックアップを取り、exe と同じフォルダへ自分でコピーして読み込みます。

有効な v1 / v2 と、ルールメタデータのない旧形式を受け付けます。ただし全手を現行ルールで再検証するため、旧版で許容された不正履歴、開局違反、禁手、終局後着手、検証期限超過は**全体を拒否**します。黙って補正はしません。読み込みは別スレッドで行い、再帰判定には全体3秒の協調期限があります。`Esc` / `Back` で取り消せます。保存は一意名で既存棋譜を上書きせず、成功・失敗を画面に通知します。

上級者向けの `--worker-directory` は引き続き利用できます。自分で管理する**既存の書き込み可能なフォルダ**を明示するときだけ使います。棋譜保存先を変える指定でも、通常起動に必要な回避策でもありません。

```powershell
& ".\Gomoku 2.0.exe" --worker-directory "C:\Users\YourName\GomokuWork"
```

## 既知の制限

- 15×15・5目が連珠の着手コアの基準です。他サイズの5目は非公式拡張、3・4・6・7目はカスタム五目並べです。簡易前三手制限は大会開局ではありません。色交換・第五手提案・時計・パスや申し立て手順等はありません。
- 深い禁手再帰は判定時間を超えることがあり、UNKNOWN のまま残します。有限のテストやレビューを、全局面の完全性・RIF 公式認証とは呼びません。
- Hard の候補絞り込み、Very Hard の固定戦術予算・静かな候補の幅制限・長連窓評価、独立した棋力証拠の不足は残っています。
- 履歴は閲覧用です。過去の局面から分岐して打つ機能や、対局中の棋譜を改変する機能ではありません。
- 保存先の空き容量・権限が不足する場合や、必要なハードリンク操作に非対応のファイルシステムでは、保存は安全に失敗します。保存の権限エラーはソース故障注入で確認しており、実機の読み取り専用保存先を認定した結果ではありません。実機のワーカー領域遮断とは別の検証です（[受入記録](<docs/G05_PORTABLE_ACCEPTANCE.md>)）。
- 非 Windows の正式配布・OS メモリ強制上限は保証しません。
